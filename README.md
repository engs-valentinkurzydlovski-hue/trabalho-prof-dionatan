# TechStore

Projeto desenvolvido para a disciplina de Interação Humano Computador.

## Sobre

A TechStore é um site simples de uma loja de tecnologia, contendo três páginas com navegação entre elas.

## Páginas

- Início
- Produtos
- Contato

## Tecnologias utilizadas

- HTML5
- CSS3
